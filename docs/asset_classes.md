# Asset Classes

## Stocks

- Enabled by default.
- Paper enabled by default.
- Live disabled by default.
- `stocks_in_play_orb_v1` is fully wired for this asset class.

## Options

- Scaffolded.
- Explicit enablement required.
- Paper disabled by default.
- Live disabled by default.
- Single-leg order fields are present.
- Multileg orders are disabled by default.

## Crypto

- Scaffolded.
- Explicit enablement required.
- Paper disabled by default.
- Live disabled by default.
- Notional and quote-currency fields are present.
- 24/7 market considerations are represented in order payload metadata.
