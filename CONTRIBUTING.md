# Contributing

Small, focused contributions are welcome. Open an issue for substantial behavior changes.
Fork the repository, create a branch, and submit a pull request to main.
Run the tests and builds documented in README.md. Explain the behavior changed and validation.
Preserve migrations, tests, upstream notices, and compatibility where practical.
Never commit credentials, user data, local databases, logs, or private exports.
Use synthetic fixtures and mocks. Do not exercise production integrations or place trades.
Contributions are accepted under GPL-3.0-only; contribute only code you are authorized to license.
Pull requests require passing CI. Review by another contributor is encouraged when available.
