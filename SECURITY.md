# Security

Report vulnerabilities privately using GitHub's **Security > Report a vulnerability**
for this repository. Do not include credentials or personal data in public issues.
Include affected versions, a minimal synthetic reproduction, and likely impact.
Only the current main branch is maintained. Response times are best effort.

Local development must use synthetic data and loopback-bound services. Cloud, payment,
banking, email, AI, and brokerage integrations require separately provisioned sandbox
credentials and must remain unconfigured during the default test workflow.
Never reuse the original application's credentials or databases.

See VALIDATION.md for known limitations and the latest migration audit results.
